# 场景配方

场景包放原始 Blender 工程和 `recipe.json`。其中 `version` 为 1，`title` 是项目名，`source` 指向包内的 .blend，`view` 可指定初始观察点。`chapters` 按区域列出，每项含 `title` 和 `steps`。

每步使用 `title`、`op` 和 `parts`。`parts` 写原始 Blender 对象名称。每个源网格必须由一个步骤安装。已安装的对象可以在后续以 `revisit: true` 再操作。相机、灯光和空对象保留在 Blender 工程里。

- `lower, raise, slide, align, insert, seat, bridge, place` 使用 `offset` 写起点相对于成品的 XYZ 偏移。
- `turn, hinge` 用 `axis`、`angle`、`pivot` 定义旋转轴、起始角度和枢轴。轴为 0、1、2，对应 X、Y、Z。
- `spread, expand, stretch` 可给定 `pivot`。定端拉展还使用 `axis`，调整原网格的轴向尺度。
- `sweep, pour, flow, tread, plant` 用 `axis` 沿边界逐步成形。`reverse: true` 反向。浏览器以切面实时预览，保存中途工程时 Blender 对真实网格切分。
- `bend` 用 `axis`、`direction` 和 `strength` 定义起始形变。预览与 Blender 使用对应的形态键。
- `cut` 用 `axis` 和 `blank` 定义待切封石。封石的 `center` 和 `size` 为 XYZ 数组。完成时封石完全切除，露出源模型的洞口。

## 选择操作方式

`op` 定义几何如何变化，`interaction` 定义玩家怎样推动变化。每一步可以写 `interaction`。省略或写 `auto` 时，工作台按 `op` 选默认方式。`interactions.json` 按几何动作列出可用方式，第一项是默认。旧工程自动沿用同一规则。生成阶段会校验两者是否匹配。

| `interaction` | 玩家操作 | 适用示例 |
| --- | --- | --- |
| `drag` | 抓住把手，推、拉、放到目标位置 | 榫头滑入槽、拉高立柱、弯合护栏 |
| `crank` | 沿弧线旋转摇柄 | 转正轮轴、翻合门板 |
| `trace` | 沿路线描画，离开路线时暂停 | 铺设石带、沿切线开槽 |
| `stamp` | 依次点按分段位置，每次推进一段 | 铺楼梯、分段布置植被、对齐结构 |
| `hold` | 按住连续推进，松手后保留进度 | 放水、注水、浇灌生长 |
| `saw` | 沿切线来回划动，逐次切开 | 切除封石、开出已有洞口 |

按构件与实际工序选方式。需要若干独立连接、摆放或成形动作时，应把源对象拆成玩家能辨认的步骤。例如水轮可先拖入轴，再转正轮体，最后按住阀门引水。对连续重复动作，可按可辨认的小段分组。已安装对象的后续操作使用 `revisit`。测试时至少完整操作一次每种用到的手势，并检查松手、接续和中途保存。

可搬动的构件先从零件盒拖到施工起点，再操作 `interaction`。`placement` 省略或为 `auto` 时按 `placement.json` 中的动作表判断。可搬动件可以显式用 `tray`，也可以在必须就地操作时用 `in_place`。注水、切割、重新加工等在现有结构上进行。按安装顺序安排每章的步骤，工作台按顺序分盒，每盒最多四件，拿走一件时保留其他零件的位置。

## 难度与组合装配

工作台把原配方作为 Hard。Medium 和 Easy 将同章相邻的操作组合，操作数分别接近 Hard 的一半和四分之一。原网格、原步骤身份和服务器进度始终保留，切换难度时沿用已完成的构件。`revisit` 和切割保留为独立操作。Medium 分别组合搬动件与原地工序，Easy 可将同章的小型装配与加工合成一个单元。界面显示每档实际操作数。连续完成同类操作时，落座和自动接续逐渐加快，轻件可顺势甩入轮廓，五声音阶的背景节拍随连击加速。大件使用较低音色、更慢落座和轻微镜头震动。声音开关统一控制音效与配乐。

需要先在旁边拼装的构件，在各自步骤上给出统一的 `assemblyOffset` XYZ 向量。构件会在该偏移位置完成局部装配。最后追加一个 `revisit: true` 的整体平移步骤，列出这些构件的全部对象名，并把 `offset` 设为相同向量。最后这一步将完整组件推入最终位置。中途保存保留桌边组件的位置。

`effects` 可定义完成后持续运行的变化。每项包含 `kind`、`parts` 和 `after`，其中 `after` 是唯一的触发步骤标题。`wheel` 另外使用 `pivot`、`axis` 和以弧度每秒为单位的 `speed`。`water` 沿带 UV 的水面材质持续推进纹理。`night` 使用 `positions` 列出的灯光位置，并逐渐切入傍晚灯光。效果从实际步骤进度解锁，在同一 3D 视图中持续运行并进入录像。

`prepare` 用 Blender 检查对象覆盖率并生成 GLB 和运行索引。源 .blend 保留原几何与材质。完成状态保存为源工程的副本，中间状态会应用真实位置、形变或切面。无跨步骤拓扑依赖的区域可以独立搭建。
