# 素材与授权

仓库的原创代码、示例几何、配方和项目图片按 GPL-3.0-or-later 发布，完整许可证在根目录 `LICENSE`。仓库提供示例的可编辑 Blender 源工程和运行所需的生成文件。

- `examples/wood-village/` 是本项目为日式水磨山居制作的模型、分批场景和搭建配方。
- `examples/spiral-mill/` 是本项目的螺旋水磨山城模型与配方。GLB 是同一模型的压缩网页资产。
- `site/*.png` 是工作台实机截图。`web/atelier-room.webp` 是为工作台生成的室内背景。
- Three.js 和 meshoptimizer 的授权通知位于 `licenses/`。构建依赖的版本和来源记录在 `package-lock.json`。
